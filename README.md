# Likhit SSC Mock Hall

Free SSC CGL / CHSL Tier-1 style mock test app.

## Features
- Best 500 Maths Part 1 (Q 1–100)
- Best 500 Maths Part 2 (Q 101–200)
- Custom mock upload (JSON)
- Live timer, question palette, mark for review
- +2 / −0.5 negative marking
- Full answer key after submit

## How to use
Open the site and click any mock.

Made for offline practice.
